Tools for looking at a code-task run directory (contract.json, result.json, memo.sqlite, events.jsonl, verdict_<i>.json). Change only scripts/audit_run.py, scripts/failure_trace.py, scripts/pilot_report.py (new) and evals/runlog.py (new); the tests are protected. Read the module docstring of tests/test_run_report.py first: it defines the report exactly.

1. Shared reader. evals/runlog.py is the one place that reads a run directory: events (via harness.events.parse_lines, which skips an undecodable line wherever it is) with the number of non-blank lines that did not decode, result.json (None when absent), and the memo. All three scripts read runs through it.

2. Keep what the two inspectors print. For a run that finished normally, audit_run.py RUN_DIR and failure_trace.py RUN_DIR... must print exactly what they print today, byte for byte. Only three things change, each a crash today:
 a. An undecodable line of events.jsonl is skipped wherever it is; the output is that of the log without it, plus a last line 'events skipped: N' only when N > 0.
 b. audit_run.py on a run with no model call (for example BLOCKED, whose result has 'tools': null) does not crash: it prints 'effective tools None', 'llm_call_started 0, llm_call 0 (ok 0, refused 0)', 'prompt_hash checked 0, mismatches 0', then the notable events and the result line, exit 0.
 c. failure_trace.py on a directory without result.json prints '##### <name>: no result.json' and goes on with the next argument.

3. scripts/pilot_report.py RUN_DIR... [--supervision FILE.json]: one JSON report over runs (success rate, known cost and cost per success, attempts, supervision minutes, skipped lines). An unknown cost is never 0, a run without result.json is neither a success nor a failure, missing minutes are null. Use evals.score.cost_is_known. Refused with 'refused: ...' on stderr and exit 2 for an argument that is not a run directory or an invalid supervision file.
