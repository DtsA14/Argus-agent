Optimize replace itertool

## Intro

Increases the performance of the `replace` itertool by removing the reliance on `windowed` as well as other minor adjustments.

I have also added the `default_arg` option to specify what default arguments are passed to the `pred` when reaching the end of the iterable. I'm not sure using `_marker` was ever good practice but I have left the default as `_marker` for backwards compatibility. We should probably think about changing this in the future however.

### Testing

**Test:**
```python
from more_itertools import replace, consume

iterable = [1, 1, 0, 1, 1, 0, 1, 1]
pred = lambda x: x == 0
substitutes = (2, 3)

%timeit -n 10000 consume(replace(iterable, pred, substitutes))
%timeit -n 10000 consume(replace(iterable*5, pred, substitutes))
%timeit -n 10000 consume(replace(iterable*10, pred, substitutes))
%timeit -n 1000 consume(replace(iterable*25, pred, substitutes))
%timeit -n 1000 consume(replace(iterable*100, pred, substitutes))
print()
%timeit -n 10000 consume(replace(iterable, pred, substitutes, count=2))
%timeit -n 10000 consume(replace(iterable*5, pred, substitutes, count=2))
%timeit -n 10000 consume(replace(iterable*10, pred, substitutes, count=2))
%timeit -n 1000 consume(replace(iterable*25, pred, substitutes, count=2))
%timeit -n 1000 consume(replace(iterable*100, pred, substitutes, count=2))
print()

iterable = [0, 1, 2, 5, 0, 1, 2, 5]
window_size = 3
pred = lambda *args: args == (0, 1, 2)
substitutes = (2, 3)

%timeit -n 10000 consume(replace(iterable, pred, substitutes, window_size=window_size))
%timeit -n 10000 consume(replace(iterable*5, pred, substitutes, window_size=window_size))
%timeit -n 10000 consume(replace(iterable*10, pred, substitutes, window_size=window_size))
%timeit -n 1000 consume(replace(iterable*25, pred, substitutes, window_size=window_size))
%timeit -n 1000 consume(replace(iterable*100, pred, substitutes, window_size=window_size))
```
