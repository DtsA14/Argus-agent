## 1. Guarantees

**Budget and money**
- **All calls through `LLMCaller.call`: HOLDS** on production paths (section 2).
- **Refuse before sending: HOLDS** with an exact counter (`llm.py:483-494`, cap `409-416`). **BY CONVENTION** otherwise:
  - Heuristic counts (`llm.py:270-280`): overspend is detected after billing (`581-586`, `run.py:442`).
  - Two processes: only the router locks. `scripts/run_code_task.py --resume` twice at once restores the same ledger in both (`steps.py:99-108`), so the attempt reservation is spent twice.
- **Every attempt reaches the ledger: HOLDS for a process crash** (`llm.py:505`; a failed `started` write raises before sending; a failed final write still charges, `521-531`, `560-566`). **BY CONVENTION for durability:**
  - `EventLog.emit` never fsyncs (`events.py:54-58`), unlike the memo (`memo.py:26`). Power loss after sending loses `llm_call_started`; resume under-counts by one worst-case call.
  - `parse_lines` skips any undecodable line, not only the last (`events.py:7-16`), and `reconcile_ledger` ignores a final event without its start (`llm.py:311-318`). A damaged line silently removes spend.
- **Integer nano-dollars: BY CONVENTION.** Spend is integer (`llm.py:133-168`); limits and cap arithmetic are float (`llm.py:145`, `160`, `413-415`; `guard.py:80-83`). No error above a nano found.
- **Unpriced refused: HOLDS** (`llm.py:120-130`, `341`). **Unknown cost null, never 0: BY CONVENTION.** An attempt with `delivery="unknown"` is written `usd_nano=0` when `failed_attempt_charge` is not `worst_case` (`llm.py:515-529`; `config.yaml:60` sets `worst_case`); a gateway 429 is always written 0 (`516-519`).
- **Heuristic not called absolute: HOLDS** (`llm.py:27-32`).

**Crash-resume**
- **Committed node result never recomputed: HOLDS** (`guard.py:55-60`, `86-88`).
- **Side effects safe twice: VIOLATED** by one path (section 3).
- **`durability="sync"`: HOLDS** at all 10 `graph.invoke` sites (grep). `update_state` passes none (`run.py:450`).
- **Reply and tool result committed before moving on: HOLDS** in `codetask/agent.py:390`, `425`. A crash between reply and commit (`agent.py:389-390`) pays for the reply twice, inside the reservation.
- **Step keys: HOLDS** (`steps.py:31-48`).
- **Reservation from ledger: HOLDS** (`steps.py:99-112`).
- **Resume after a config change: BY CONVENTION.** Only budget profile and tools are checked (`run.py:317`, `327`). A changed role model misses every step key, so the attempt restarts at step 0 on a half-edited workspace.

**The failure:** `Toolbox.run` catches only `PathEscape` and `FileNotFoundError` (`tools.py:254-257`). Reproduced as uncaught:
- WriteFile onto an existing directory (`IsADirectoryError`).
- A name over 255 bytes; the temp suffix adds about 25 (`fs.py:110`).
- Content with a lone surrogate (`tools.py:405`).

The reply is already committed, so every resume replays the same call and crashes again: a model-chosen input wedges the run permanently. A surrogate in a reply fails `memo.put` itself (`agent.py:390`): paid, lost, bought again.

## 4. Path jail

- **Traversal: HOLDS** (`fs.py:44-63`).
- **Symlinks, including agent-made: HOLDS.** Each component opened `O_NOFOLLOW` by descriptor (`fs.py:74-95`, `113`, `139`); reproduced. Validation mounts read-only (`sandbox.py:268`).
- **Hardlinks:** writes replace the inode; making one needs host access.
- **Special files: HOLDS** (`fs.py:139-148`).
- **TOCTOU:** jail operations are safe. `snapshot()` does `lstat` then `open` by path, no size limit (`workspace.py:37-42`); exploitable only with a concurrent writer, which the code-task path lacks. BY CONVENTION.
- **Case and unicode:** scope globs compare strings (`contract.py:101`). On a case-insensitive file system the tool check is bypassable; acceptance's snapshot still catches it.
- **Long paths:** unhandled (section 3).
- **Code outside Docker: none.** Host side only parses (`tools.py:152`, `182`); no `exec`, `eval`, `shell=True`.

## 6. Sandbox

Flags (`sandbox.py:135-149`): `--network none`, `--read-only`, tmpfs `/tmp` 64m, `--user 65534:65534`, `--cap-drop ALL`, `no-new-privileges`, memory 512m with no swap, 1 cpu, 128 pids, workspace `ro` for validation, `--log-driver none`, pinned image. Absent: file-size and open-file limits. `ARGUS_SANDBOX_IMAGE` overrides the image (`sandbox.py:84`).

- **Agent-written files** run as nobody, offline, read-only, keyless. `-I` blocks `PYTHON*` and user site; pytest still loads workspace `conftest.py` if scope allows writing it.
- **Verdict integrity is not a boundary.** The result is parsed from the test process's own stdout (`validation.py:231-272`, `323-381`). Writable code in that process can print a consistent report and `os._exit(0)`. The file admits this for unittest (`validation.py:23-25`); pytest is the same, with no nonce.
- **Labelling:** auto-validation and feedback are labelled (`agent.py:34-40`); ReadDocs is fenced (`tools.py:349-352`). **VIOLATED** for the RunValidation tool: raw JSON with `output_tail`, unlabelled (`tools.py:429-432`).

## Top 5 fixes

1. **Run wedge.** `except (OSError, UnicodeError)` in `Toolbox.run` returning "Refused" (`tools.py:254`); escape surrogates before `memo.put`.
2. **Ledger durability.** `flush` + `os.fsync` in `EventLog.emit` (`events.py:57`); treat an undecodable non-final line as an error.
3. **Forgeable verdict.** No small fix. State it for pytest and never apply a DONE job unread.
4. **Unlabelled sandbox output.** Prefix RunValidation's result with the auto-validation label (`tools.py:429`).
5. **Keys.** Replace configured key values in every error string before emit or raise; give git a minimal environment; flock the run directory in `run_code_task`.
