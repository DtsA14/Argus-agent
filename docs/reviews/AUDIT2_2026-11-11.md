## 1. Forgeable verdict

The limit: the trusted assertion and the untrusted code share one process. No option below makes the verdict unforgeable; they differ in which forgeries become failures.

| Option | Stops | Does not stop | Cost | Mutation test |
|---|---|---|---|---|
| Must-fail sentinel | "All passed" + `os._exit(0)`; blanket neutralising of asserts or of pytest's runner | A forger that reads the sentinel and reports it correctly; replacing one protected test or its constants (the chain-probe cheat) | ~60 lines, no runtime | Drop each expected outcome; forger fixtures must fail |
| Per-run nonce | Stale or replayed output | Anything in-process (argv is readable) | ~10 lines | Accept a record without the nonce |
| Separate collection | Dropped or invented node ids | Forging outcomes of the right ids | One extra run at approve (exists: `collect_nodes`) | Skip the set comparison |
| Unreachable result path | Nothing: same uid and address space as pytest | Everything | New mount or fd | n/a |
| Run twice | Flaky results | A forgery is deterministic | 2x runtime | n/a |
| Black-box tests in another process | The whole class | Unit tests cannot be written this way | Large | n/a |

**Recommend:** the first three together, reusing the recorder the red check already has (`validation.py:590-632`). The generic forgery becomes a failure; targeted tampering is still left to the reader, so "never apply a DONE job unread" stays.

```python

CANARY = '''
def test_pass_{n}(): assert 1 == 1
def test_fail_{n}(): assert 1 == 2
def test_error_{n}(): raise RuntimeError("{n}")
'''
def green_argv(nonce, targets):
    return ["python3", "-I", "-B", "-c", GREEN, nonce, *targets]
# GREEN, in the container: write CANARY to /tmp/argus_<nonce>/test_canary_<nonce>.py, then
#   rc = pytest.main([*FIXED, canary, *targets], plugins=[Record()])   # canary first
#   print(nonce + json.dumps({"rc": int(rc), "outcomes": Record.outcomes})); sys.exit(rc)
def judge_green(spec, r, nonce):
    rec = record_after(r["stdout"], nonce)          # None: no record, or more than one
    if rec is None:
        return fail(spec, ["no harness record"])
    out, c = rec["outcomes"], f"test_canary_{nonce}.py::"
    want = {c + f"test_pass_{nonce}": "passed",
            c + f"test_fail_{nonce}": "failed:AssertionError",
            c + f"test_error_{nonce}": "failed:RuntimeError"}
    problems = [f"canary {k}: {out.get(k)!r}" for k, v in want.items() if out.get(k) != v]
    rest = {k: v for k, v in out.items() if not k.startswith(c)}
    if r["exit_code"] != 1 or rec["rc"] != 1:
        problems.append("exit code is not the canaries' 1")
    if set(rest) != set(spec["expected_nodes"]):    # frozen at approve, collected without agent code
        problems.append("nodes differ from the approve-time collection")
    problems += [f"{k}: {v}" for k, v in rest.items() if v != "passed"]
    return verdict(spec, problems, rec)
```

## 2. Remaining files

**Budget and money**
- **Paid web requests: HOLDS.** Refused before sending, `started` written first, charge in `finally` (`paid.py:171-197`).
- **Unknown cost is charged as nothing: VIOLATED.** `cost_usd` returns `None` for a cache write without a write price (`pricing.py:66-68`); the ledger gets null, but `charge` adds 0 (`llm.py:165`) and `reconcile_ledger` skips it (`llm.py:319-320`). Scenario: a direct OpenAI-compatible provider reports cache-creation tokens for a model priced without `cache_write_5m`; every such call is free to the cap.
- **Zero and negative prices: BY CONVENTION.** `check_priced` tests only for a missing entry (`llm.py:122`); `cost_usd` never checks sign (`pricing.py:64-75`). `{input: 0, output: 0}` on a direct provider makes a finite cap vacuous; a negative price lowers recorded spend. Only the gateway guards this (`gateway.py:44-48`, `94-96`).
- **Zero written on a billing assumption: BY CONVENTION.** An error with DeepSeek's own body, or an empty 200, is recorded as 0, not null (`paid.py:98-103`, `117-120`).
- **Gateway pin: BY CONVENTION.** A reply that names no provider passes (`gateway.py:119-120`); the name match is a prefix test (`121-122`), so "Deep" satisfies a `deepinfra` pin.

**Web tools**
- **SSRF and redirects (ReadDocs): HOLDS.** Exact allowlisted host, no port, query or userinfo (`web_fetch.py:79-106`); one resolution, every address global, connection pinned to the checked address (`109-143`, `248-256`); each redirect re-checked and counted (`262-266`).
- **Response size: HOLDS** (`web_fetch.py:157-169`; `deepseek_web.py:55`). A slow-drip body is ended only by the parent's timeout (`web.py:81`).
- **Paid search/fetch: HOLDS.** Fixed host, no redirects, key on stdin, empty environment (`deepseek_web.py:22-24`, `47-52`; `paid.py:88-91`). The fetched URL is checked for shape only (`paid.py:54-82`); DeepSeek's servers reach it, not this machine.

**Plans and tools**
- **Contract: HOLDS.** Commands allowlisted, limits bounded (`contract.py:171`, `213-216`).
- **Draft files: BY CONVENTION.** `materialize` writes model-chosen paths with plain `Path` calls, not the jail (`draft.py:309-324`). It is safe only because `_plain` is lexical (`intake.py:95-97`) and the intake refuses symlinks (`intake.py:125`).

**Staging**
- **Commit content executed outside a container: none found.** The host runs `git archive | tar -x`, compares the tree, and changes modes without following links (`stage.py:511-515`, `531-572`). Code runs only in containers with no network, read-only root, no capabilities (`stage.py:251-257`; `stage_viewer.py:202-207`). The proxy opens files `O_NOFOLLOW` (`stage_viewer.py:582-628`) and checks the socket peer's pid (`stage.py:455-472`).
- **One host-side read follows a link:** `package.json` of the commit is read with `read_bytes()` (`stage_viewer.py:411`). A symlinked one makes the host parse another file; only a JSON error position or dependency names surface. Low.
- **`stage check` is forgeable** by a conftest in the commit; the file says so (`stage.py:742`). Same class as part 1.
